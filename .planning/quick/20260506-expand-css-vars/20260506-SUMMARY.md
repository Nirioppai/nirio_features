# Quick Task: Expand CSS-var surface, dark mode, theme helpers

## What was done

Addressed PROBLEM 1 + PROBLEM 3 from the beygg agent report, plus shipped the optional
MUI and Tailwind theme bridge helpers.

### Task 1 — CSS-var surface expansion (widget.ts)

Replaced all hardcoded color values in the shadow-DOM `<style>` block with `--fs-*` CSS
custom properties. The full new surface:

- **Surfaces**: `--fs-surface`, `--fs-surface-elevated`, `--fs-surface-muted`
- **Text**: `--fs-text-muted`, `--fs-text-strong` (+ existing `--fs-text-color`)
- **Borders**: `--fs-border`, `--fs-border-strong`, `--fs-border-focus`
- **States**: `--fs-hover-bg`, `--fs-active-bg`
- **Status pills** (bg/fg pairs): `--fs-status-{under-review|planned|in-progress|completed|declined}-{bg|fg}`
- **Type pills** (bg/fg pairs): `--fs-type-{new-feature|feature-update|bug-report}-{bg|fg}`
- **Error**: `--fs-error-color`, `--fs-error-bg`, `--fs-error-border`
- **Backdrop/modal**: `--fs-backdrop`, `--fs-modal-bg`
- **Radii**: `--fs-radius-sm`, `--fs-radius-md`, `--fs-radius-lg`
- **Spacing**: `--fs-space-1` … `--fs-space-6`
- **Typography**: `--fs-font-mono`, `--fs-font-size-base`, `--fs-font-size-heading`

Light defaults set on `:host { }`. Dark preset set on `:host([data-color-scheme="dark"])`.

Also added per-type CSS classes on the type badge (`fs-card-type--new-feature` etc.) in
both the feed cards and the detail dialog, backed by a new `typeToClassName()` helper in
`status.ts`.

### Task 2 — colorScheme prop + auto dark mode (widget.ts, status.ts)

Extended `WidgetTheme`:

```typescript
colorScheme?: 'light' | 'dark' | 'auto';  // default: 'auto'
```

`applyTheme()` now:

- `'dark'` → sets `data-color-scheme="dark"` on the host element
- `'light'` → removes the attribute
- `'auto'` → wires `prefers-color-scheme: dark` MediaQueryList listener; cleaned up in `disconnectedCallback()`

### Task 3 — Theme helpers (src/themes/mui.ts, src/themes/tailwind.ts)

**`applyMuiTheme(el, theme)`** — maps a MUI Theme palette slice to all `--fs-*` vars in
one call, sets `data-color-scheme`, returns a no-op unsubscribe fn for API consistency.
Zero hard dependency on `@mui/material` (structural types only).

**`applyTailwindTheme(el, opts)`** — sets primary, font, radius scale, status palette, and
drives color-scheme by watching `document.documentElement.classList` for the `dark` class.
Returns an unsubscribe fn that disconnects the MutationObserver.

Both helpers are tree-shakeable via subpath exports:

```
@nirioppai/feature-suggestions/themes/mui
@nirioppai/feature-suggestions/themes/tailwind
```

Build outputs (6 new files):

```
dist/themes/mui.cjs.js     dist/themes/mui.esm.js     dist/themes/mui.d.ts
dist/themes/tailwind.cjs.js dist/themes/tailwind.esm.js dist/themes/tailwind.d.ts
```

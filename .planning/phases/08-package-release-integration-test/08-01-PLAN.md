## Trust Boundaries

| Boundary                            | Description                                                                                           |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------- |
| built bundle -> host app runtime    | The published artifact must accept host-provided props without assuming source-tree internals         |
| host app adapter -> widget UI       | Untrusted integration wiring can break feature flows if the adapter contract is exercised incorrectly |
| release command -> packaged tarball | A passing unit suite is insufficient if the built tarball omits required files or breaks dist imports |

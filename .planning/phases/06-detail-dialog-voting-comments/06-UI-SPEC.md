# Phase 6 — UI Design Contract: Detail Dialog + Voting + Comments

> Visual and interaction contract for Phase 6. Generated by gsd-ui-researcher.
> All values derived from existing shadow DOM styles in `src/widget.ts`, `src/feed.ts`, and `src/submission.ts`.

---

## Design System

| Property                | Value                                                         |
| ----------------------- | ------------------------------------------------------------- |
| Tool                    | none                                                          |
| Preset                  | not applicable                                                |
| Component library       | none — vanilla Web Components, shadow DOM                     |
| Icon library            | none — Unicode characters only (▲ ✕ 💬)                       |
| Font                    | `var(--fs-font, system-ui, sans-serif)` — inherited from host |
| Styling approach        | Inline `<style>` block inside `renderShell()` shadow DOM      |
| Distribution constraint | Pure CSS + HTML strings; zero external dependencies           |

---

## Spacing Scale

Multiples of 4, consistent with existing widget spacing.

| Token | Value | Usage                                                                               |
| ----- | ----- | ----------------------------------------------------------------------------------- |
| xs    | 4px   | Badge internal padding (vertical), gap between meta items in comment                |
| sm    | 8px   | Badge horizontal padding, button gap, comment body top margin, comment item padding |
| base  | 16px  | Dialog section gap, form action margin-top, comments root gap                       |
| lg    | 24px  | Dialog body padding (horizontal + vertical), section separators                     |
| xl    | 32px  | Empty/loading state padding                                                         |

Exceptions:

- Dialog overlay: `padding: 16px` (prevents modal touching viewport edge on narrow screens)
- Close button: `24px × 24px` minimum touch target, positioned `top: 16px; right: 16px`
- Comment divider: `border-top: 1px solid #f3f4f6` (not a spacing value — structural)

---

## Typography

All sizes in rem for accessibility scaling. Values match the existing widget scale.

| Role                  | Size            | Weight | Line Height | Usage                             |
| --------------------- | --------------- | ------ | ----------- | --------------------------------- |
| Dialog title (h2)     | 1.125rem (18px) | 600    | 1.3         | Suggestion title in dialog header |
| Comments heading (h3) | 0.875rem (14px) | 600    | 1.4         | "Comments (N)" section label      |
| Body                  | 0.875rem (14px) | 400    | 1.5         | Suggestion details, comment body  |
| Label                 | 0.875rem (14px) | 600    | 1.4         | Form labels, comment author name  |
| Meta / caption        | 0.8rem (12.8px) | 400    | 1.4         | Timestamp, vote count             |
| Badge                 | 0.75rem (12px)  | 400    | 1           | Type badge, status badge          |

No new font sizes introduced beyond this set.

## Interaction States

| Element                           | State                                 | Visual Change                                                                   |
| --------------------------------- | ------------------------------------- | ------------------------------------------------------------------------------- |
| `.fs-dialog-overlay`              | Dismiss on click outside `.fs-dialog` | Close dialog                                                                    |
| `.fs-dialog-close`                | hover                                 | `background: #f3f4f6`, `color: #111827`                                         |
| `.fs-dialog-close`                | focus-visible                         | `outline: 2px solid var(--fs-primary-color)`                                    |
| `.fs-upvote-btn` (unvoted)        | hover                                 | 10% primary tint background                                                     |
| `.fs-upvote-btn` (unvoted)        | active                                | 20% primary tint background                                                     |
| `.fs-upvote-btn--voted`           | hover                                 | `opacity: 0.88`                                                                 |
| `.fs-upvote-btn`                  | focus-visible                         | `outline: 2px solid var(--fs-primary-color)`, `outline-offset: 2px`             |
| `.fs-upvote-btn`                  | disabled                              | `opacity: 0.45`, `cursor: not-allowed`                                          |
| `.fs-form-input` (textarea)       | focus                                 | `border-color: var(--fs-primary-color)` (inherits existing rule)                |
| `.fs-btn--primary` (Post comment) | hover                                 | `opacity: 0.9` (inherits existing rule)                                         |
| `.fs-btn--primary` (Post comment) | disabled / submitting                 | `opacity: 0.6`, `cursor: not-allowed` (add `disabled` attr during async submit) |
| `Escape` key                      | pressed while dialog open             | Close dialog, return focus to trigger card                                      |
| Click outside dialog              | anywhere on `.fs-dialog-overlay`      | Close dialog                                                                    |

**Focus trap behavior:**

- On open: move focus to `.fs-dialog` container (`tabindex="-1"`) or first focusable child (`#fs-dialog-close`)
- Tab cycles within dialog only — intercepted via `keydown` listener checking `focusable` elements inside `.fs-dialog`
- On close: return focus to the `.fs-card[data-id]` that triggered the dialog

## Accessibility Notes

| Requirement                            | Implementation                                                                                                                        |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `role="dialog"`                        | On `.fs-dialog`                                                                                                                       |
| `aria-modal="true"`                    | On `.fs-dialog`                                                                                                                       |
| `aria-labelledby="fs-dialog-title"`    | Points to the `<h2>` in dialog header                                                                                                 |
| `aria-describedby="fs-dialog-details"` | Points to `<p class="fs-dialog-details">`                                                                                             |
| Focus trap                             | Intercept `Tab`/`Shift+Tab` inside `.fs-dialog`; query all `button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])` |
| Escape key                             | `keydown` listener on the shadow root; `e.key === 'Escape'` closes the dialog                                                         |
| Click outside                          | `mousedown` on `.fs-dialog-overlay` (not `.fs-dialog`) closes dialog                                                                  |
| Focus management on open               | Set focus to `#fs-dialog-close` (first focusable)                                                                                     |
| Focus management on close              | Return focus to the `.fs-card[data-id="${id}"]` that was clicked                                                                      |
| Upvote toggle semantics                | `aria-pressed="true/false"` on the upvote button                                                                                      |
| Comment time element                   | Use `<time datetime="ISO-8601">` for machine-readable dates                                                                           |
| Status badge screen reader             | Badge text is the full status name (not abbreviated)                                                                                  |
| Reduced motion                         | See Animation section                                                                                                                 |

## Animation / Motion

All transitions must be skipped when `prefers-reduced-motion: reduce` is active.

### Overlay fade

```css
.fs-dialog-overlay {
  animation: fs-overlay-in 180ms ease-out forwards;
}

@keyframes fs-overlay-in {
  from {
    opacity: 0;
  }
  to {
    opacity: 1;
  }
}
```

### Dialog slide-up + scale

```css
.fs-dialog {
  animation: fs-dialog-in 200ms ease-out forwards;
}

@keyframes fs-dialog-in {
  from {
    opacity: 0;
    transform: translateY(10px) scale(0.98);
  }
  to {
    opacity: 1;
    transform: translateY(0) scale(1);
  }
}
```

### Close (programmatic removal — no reverse animation needed)

Remove the overlay element from the DOM directly. No exit animation in v1 (keeps implementation simple; a fade-out can be added later without a contract change).

### Reduced motion override

```css
@media (prefers-reduced-motion: reduce) {
  .fs-dialog-overlay,
  .fs-dialog {
    animation: none;
  }
}
```

## Trust Boundaries

| Boundary                               | Description                                                                       |
| -------------------------------------- | --------------------------------------------------------------------------------- |
| user input -> comment submission       | Untrusted freeform comment text crosses from UI input into stored comment records |
| widget -> storage adapter              | Client-side vote and comment actions mutate persisted suggestion metadata         |
| build artifacts -> consumer smoke test | Executable package output is consumed by the integration test through `dist/`     |
